# Food Delivery Demand Analytics

| Folder | Purpose |
|---|---|
| `src/` | Python source code |
| `data/raw/` | Raw data |
| `data/processed/` | Processed data |
| `docs/` | Documentation |
| `tests/` | Test files |

## Setup Instructions

1. Create a Python virtual environment.
2. Install the required packages.
3. Run the Python scripts.

## Usage

Run the pipeline from the project root:

python src\main.py

The application provides options to:

1. Fetch and display the top 10 mock restaurants.
2. Add a new restaurant.
3. Calculate commission for active records.
4. Save and load records from JSON.
5. Exit the application.
